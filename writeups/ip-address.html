3. The Subnet Mask: Defining Boundaries

An IP address contains two pieces of information: the Network ID and the Host ID. The Subnet Mask is what tells the computer where the network ends and the host begins.

The Logic

A Subnet Mask looks like an IP address (e.g., 255.255.255.0). Where you see 255, it means "This part is the Network Address." Where you see 0, it means "This part is for individual Devices."

Example: 192.168.1.50

If Mask is 255.255.255.0:

192.168.1.50

Network Portion | Host Portion

4. CIDR Notation (Shorthand)

Typing 255.255.255.0 is slow. Engineers use CIDR (Classless Inter-Domain Routing) notation instead. It counts the number of "1" bits in the mask.

CIDR Prefix Decimal Mask Available Hosts
/8 255.0.0.0 16.7 Million
/16 255.255.0.0 65,536
/24 255.255.255.0 254
/32 255.255.255.255 1 (A single specific IP)
